# Рома убегает от какашки

Простая аркада на HTML5 canvas в стиле Flappy Bird: Рома убегает от гигантской злой какашки, пролетая между блочными (Minecraft-style) трубами.

Игра — один самодостаточный файл `index.html`, без сборки и зависимостей. Открывается прямо в браузере.

## Как играть

Пробел / клик / тап — взлететь. Не врезайся в трубы, землю и потолок.

## Возможности

- 6 скинов персонажа, покупаются за монеты в игровом магазине
- Бонусы: щит, расширение прохода, рывок, магнит для монет
- Комбо и множители очков, золотые трубы
- Босс-битва каждые 100 очков — босс появляется поверх обычного забега, не останавливая игру
- Онлайн-рейтинг топ-10 игроков (Firebase Firestore)

## Публикация на GitHub Pages

1. В репозитории Settings → Pages выбери ветку и папку (обычно `main` / `/ (root)`).
2. Файл `index.html` должен лежать прямо в корне этой ветки — не в подпапке, если выбран root.
3. Дождись, пока Actions/Deployments покажет успешный билд, затем открой ссылку сайта.

## Настройка онлайн-рейтинга (Firebase)

В самом низу `index.html` есть блок `<script type="module">` с объектом `firebaseConfig` — туда уже вставлен конфиг проекта. Чтобы рейтинг работал, в консоли Firebase должны быть:

- создана база Cloud Firestore;
- опубликованы правила доступа, разрешающие чтение коллекции `scores` всем и запись — только в документ с соответствующим `playerId`.

Если Firebase недоступен или не настроен — игра всё равно работает, просто рейтинг покажет "Рейтинг временно недоступен".
